# Copywriting: Voice & Tone Guidelines

When generating text for Micro Rocket IT, adhere to this brand persona.

## Brand Personality Keywords
* Tone: Professional, forward-thinking, technical, sleek
* Energy: Precise, high-speed, reliable
* Audience: Modern startups, SMEs, and enterprise tech leaders

## Grammar & Mechanics rules
* **Headings:** Use Title Case for main headings (H1, H2).
* **Punctuation:** Clean and intentional. Use exclamation points sparingly to emphasize innovation or speed.
* **Clarity:** Technical yet accessible. Explain complex concepts with clarity.
* **Confidence:** Use language that implies mastery and future-proofing (e.g., "Future-Proof Solutions," "Precision Engineering," "Agile IT").

## Terminology Guide

| Do Not Use | Use Instead |
| :--- | :--- |
| "Fixing", "Mending" | "Optimizing", "Resolving", "Engineering" |
| "Slow", "Laggy" | "Latency-prone", "Legacy" |
| "Old", "Basic" | "Legacy", "Foundational" |
| "Simple" | "Streamlined", "Efficient" |
